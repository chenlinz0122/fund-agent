# 基金筛选 Agent

> A 股公募基金的筛选、组合分析、费后期望体检、模拟盘与自训练闭环。
> 数据免费（akshare / 天天基金）、计算纯本地、可完全离线运行，**不对接任何真实交易通道**。

```
python 3.9+   fastapi   pandas/numpy   echarts   254 tests, all offline
```

这个项目不预测市场。它做的事情是：把"这只基金过去表现如何、扣完费用还剩多少、
这个排名对未来有没有预测力、这套参数是不是过拟合出来的"这几个问题，
变成**可以被代码检验、可以被测试守住**的结论，而不是提示语里的一句免责声明。

## 它刻意不做什么

- 不预测收益率、不推荐"必涨"的基金；所有结论都带样本外检验与费用口径。
- 不做空、不加杠杆：杠杆上限与做空权限是**常量**，既不在参数搜索空间里，也不能被请求体覆盖。
- 不让模型算数：LLM 只负责把代码算好的事实写成话，打分、筛选、晋升全部由确定性代码完成。
- 不自动采纳进化结果：挑战者必须过三重闸门，且晋升要人工确认——确认那一刻才是"冻结日"。

## 核心能力

**筛选与问答**
- 仪表盘多条件筛选，并如实报告哪些条件真正生效、哪些因数据源缺字段被忽略（旧版会静默吞掉）。
- 规则引擎 + 可选 LLM 的问答：榜单/筛选/对比/费用这类确定性问题不消耗 token；
  每条回答标注来源（规则引擎 / LLM / 已降级）、识别到的意图与耗时。
- 内置 51 条基金知识库与财经资讯降级缓存。

**风险与组合分析**
- 年化收益/波动、最大回撤、Sharpe/Sortino/Calmar、VaR/CVaR、Beta/Alpha、胜率。
- 组合优化（最大夏普/最小方差/风险平价/有效前沿）+ 无杠杆与 long-only 护栏。
- 相关性矩阵、高相关预警、**有效下注数**（8 只基金可能只等于 1 个方向）、风险贡献占比。
- 回测支持真实月度再平衡与换手成本（旧版把"月度"偷偷实现成了"每日"）。

**期望值与反过拟合（这个项目的灵魂）**
- 费后期望：按基金类型的申购/赎回/管理/托管费率假设，输出费后年化与费后夏普；
  持有不足 7 天计入惩罚性赎回费。毛收益为正但费后为负时，直接说"费用把期望拉成了负值"。
- 收益集中度：前 5 个交易日贡献超过一半正收益 → 标记「把噪声当规律」。
- 样本外检验：walk-forward 滚动算 Rank IC 与 t 统计量；Deflated Sharpe 按**真实尝试次数**抬高门槛。
- 参数平原：邻域扰动 10% 后分数塌陷 → 判定"解在针尖上"，不是规律。
- 基准是无脑定投：任何策略模拟都同时给出 Ghost DCA 对照，跑不赢就直接说跑不赢。

**模拟盘（基金规则，不是股票规则）**
- T 日提交、按 T+1 之后公布的**未知净值**确认；申购按金额、赎回按份额。
- 份额按**批次**记账，所以阶梯赎回费算得清（<7 天 1.5% / <30 天 0.75% / <1 年 0.5% / 之后 0）。
- 现金不足直接拒单不透支；确认前不能撤单；每笔订单记录成交净值与实扣费用。
- 「按策略自动走一天」：结算 → 读状态 → 四个天平定仓位 → 不交易带过滤 → 申赎。

**自训练闭环**
- 进化时把最近 N 天**整段藏起来**，挑战者只准用更早的数据进化，留出段是它第一次见。
- 三重闸门：参数平原 / Deflated Sharpe / walk-forward，任一不过直接 `rejected`。
- 晋升必须人工确认，确认那一刻记为**冻结日**；只有冻结日之后的净值才算样本外证据。
- 复盘报告里"样本外天数 = 0"会原样显示，并写明"当前成绩全部来自样本内，不构成验证"。

**工程**
- 六层架构（config / core / sources / analysis / services+agent / api），依赖方向单向；
  `main.py` 113 行只做组装，akshare 只出现在 `sources/`。
- 254 项测试全部离线可跑；限流、重试、按接口熔断、缓存降级齐备。
- 前端明暗双主题（跟随系统、记住选择、快捷键 `T`）、等宽数字表格、涨跌着色；
  ECharts 走 CDN 且带本地副本兜底，断网也能出图。

## 快速开始

```bash
git clone <your-fork-url> fund-agent && cd fund-agent
pip install -r requirements.txt
python main.py                 # http://localhost:8000
python -m pytest tests/ -q     # 254 项，全部离线，不需要 API Key
```

首次加载排名数据需联网抓取（约 2 万条，缓存 4 小时）；上游不可用时自动降级到旧缓存。

## 使用方法（第一次上手）

1. **看大盘**：打开首页「仪表盘」，默认展示全市场排名；用类型/收益区间筛选，
   点某只基金的「详情」看净值走势、风险指标和**费后期望**（毛收益扣完费用还剩多少）。
2. **问问题**：切到「智能问答」。不配 Key 也能用（规则引擎）；配了 Key 后，
   用工具栏的「启用 LLM」开关决定要不要让模型参与。试试：
   `推荐几只稳健的债券基金` / `000001 一年买卖 8 次划不划算` / `基金该怎么控制仓位，止损有用吗`。
   每条回答下方会标注是规则还是 LLM 答的、识别到什么意图、花了多久。
3. **体检一个组合**：「组合分析」里填 2-12 只代码，依次点：
   指标与相关性 → 组合优化 → 回测 → 费后期望对照 → 稳健性体检 → 当前仓位档位 → 策略模拟 → 参数进化。
   重点看两个红色结论条：**样本外 Rank IC 是否接近随机**、**Deflated Sharpe 是否到 95%**。
   没到，就说明这套排名/参数只是历史好看。
4. **开一个模拟盘**：「模拟盘」tab → 填账户名、初始资金、跟踪代码 → 开户（勾选立即建仓）。
   然后点「按策略自动走一天」：它会先结算昨天提交的订单（T+1 未知净值撮合），
   再按四个天平决定今天要不要调仓；「只看今日决策」可以只预览不下单。
   持仓表里每一笔份额都标着**持有天数和当前适用的赎回费档**，不足 7 天会标红"惩罚 1.5%"。
5. **让它自己训练**：同一页下方填代码与留出段天数 → 「跑一轮」。
   结果会告诉你三重闸门过了几关；全过才会成为挑战者，然后你在「策略档案」里点
   「晋升为冠军」——**这一刻就是冻结日**，之后账户的盈亏才算样本外证据。
   闸门不过的记录会直接标成"被拒"，不用管它。
6. **挂成每日任务**（可选，Windows）：

   ```bat
   schtasks /Create /TN fund-agent-train /SC DAILY /ST 20:30 ^
     /TR "python E:\fund-agent\train.py --codes 002910,110022,161725 --auto"
   ```

   `--auto` 会让所有模拟账户按当前冠军规则走一天；想每周进化一次就另建一个
   跑 `--rounds 1` 的任务。进化结果不会自动上岗，仍等你在页面上点晋升。

## 配置 LLM（可选）

不配置也能用（规则引擎）。配置后仅对开放式问题调用模型：

```bash
# Windows PowerShell
$env:LLM_API_KEY="your-api-key"
$env:LLM_API_BASE="https://dashscope.aliyuncs.com/compatible-mode/v1"
$env:LLM_MODEL="qwen-turbo"
$env:LLM_BUDGET_TOKENS="200000"    # 预算耗尽自动降级回规则引擎
python main.py
```

免费方案：阿里云通义千问（有免费额度）或本地 Ollama（`LLM_API_BASE=http://localhost:11434/v1`）。

```

sources/         外部数据唯一出入口（只有这里 import akshare）

  metrics 风险指标        correlation 相关性与有效下注数   portfolio 优化+无杠杆护栏
  backtest 回测           factors 多因子打分               expectancy 费后净期望
  validation 样本外检验+DSR                                abg ABG 滤波器(P/V/A)
  signals 状态→仓位档位   risk_rules 止盈止损+不交易带     simulation 可插拔模拟管线
  search 遗传搜索+参数平原                                 archive 冠军/挑战者档案
paper/           模拟盘账本（批次记账、T+1 未知净值撮合）与自动下单引擎
services/        用例编排（筛选、详情、组合、模拟、进化、模拟盘），显式接收依赖
agent/           问答意图路由、知识库、规则处理、LLM 客户端、自训练闭环
api/             HTTP 层：schemas、依赖注入、routers/{funds,portfolio,chat,system,simulation,paper,training}
container.py     组合根，唯一的运行期实例集合
main.py          只做应用组装（113 行）
train.py         自训练命令行入口（可挂计划任务）
static/          前端单页 + 主题/面板脚本 + ECharts 本地副本
docs/reference/  设计来源：作者公开的 GA 进化系统与 ABG 平仓文档、往期视频元数据
tests/           按层组织的 254 项测试（离线）
```

依赖方向严格自上而下。改代码前先查 **[ARCHITECTURE.md](ARCHITECTURE.md)** 里的
「要改 X 看哪个文件」表与硬约束清单。

## API 一览（节选）

| 路径 | 用途 |
|---|---|
| `POST /api/screen` | 条件筛选，返回 `applied_filters` / `ignored_filters` |
| `GET /api/fund/{code}` | 详情：净值 + 指标 + 费后期望 |
| `POST /api/chat` | 问答；`use_llm=false` 强制走规则引擎 |
| `POST /api/portfolio/analyze` | 指标 + 相关性 + 打分 + 有效下注数 + 风险贡献 |
| `POST /api/portfolio/robustness` | walk-forward + Deflated Sharpe 反过拟合体检 |
| `POST /api/portfolio/expectancy` | 一组基金的费后期望对照 |
| `POST /api/portfolio/simulate` | 策略模拟：状态→仓位→出场→成本（含定投基准） |
| `POST /api/portfolio/evolve` | 遗传搜索 + 参数平原 + 蒙特卡洛终审 |
| `POST /api/paper/accounts` | 开模拟账户（开户即记冻结日） |
| `POST /api/paper/accounts/{id}/auto` | 按冠军规则自动走一天 |
| `POST /api/train/round` | 跑一轮自训练（进化 → 闸门 → 留出段首考） |
| `POST /api/train/promote` | 人工晋升为冠军（记录冻结日） |
| `GET /api/train/review` | 复盘报告（数字由代码算，叙述可选 LLM） |

完整 34 个路由见启动后的 `/docs`。

## 自训练与模拟盘的四条纪律

| 纪律 | 为什么 |
|---|---|
| 留出段在进化时被整段藏起来 | 否则"样本外"只是自欺 |
| 晋升那一刻才记冻结日，其后净值才算样本外 | 否则模拟盘做三年仍在拟合同一段历史 |
| 闸门不过直接 rejected，不入库为挑战者 | 进化器总能找到针尖解并称之为最优 |
| LLM 只写叙述，不参与打分/筛选/晋升 | 模型一幻觉，整条链的数字就不可信 |

命令行用法（便于定时任务）：

```bash
python train.py --codes 002910,110022,161725 --rounds 1   # 进化一轮并入库
python train.py --open --codes 002910,110022              # 开户并等权建仓（记冻结日）
python train.py --auto                                    # 所有账户按冠军规则走一天
python train.py --review pa-xxxx                          # 复盘（含样本外天数）
python train.py --promote st-xxxx                         # 人工晋升
```

## 设计来源

架构与"期望值纪律"借鉴自 B 站/YouTube 频道「可乐AI实验室」的量化系列视频，
其中两份作者公开的设计文档已收录在 `docs/reference/`：

- `ga_evolution_design.md` —— GA 进化系统：环境/季节/基因三层、10-40-50 种群配比、
  块级正交交叉、突变斜坡、挑战者不自动晋升、蒙特卡洛不参与 fitness。
- `abg_exit_design.md` —— ABG（α-β-γ）滤波器与平仓决策顺序（止损 → 止盈/抛物底 → 持有）。

哪些是直接照搬、哪些是按日频公募基金场景改写的、哪些只是根据视频标题推断的，
在 `ARCHITECTURE.md` 末尾的「设计来源对照」表里逐条标注。
